# J.A.R.V.I.S. (Just A Rather Very Intelligent System) - v2.2.0

![JARVIS Logo](https://raw.githubusercontent.com/username/repo/main/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png)

**JARVIS** es un asistente inteligente personal diseñado para Android, inspirado en la sofisticación y eficiencia de los sistemas de inteligencia artificial de ciencia ficción. Este proyecto combina el poder de LLMs modernos (GPT-4o, Gemini, Copilot) con una integración profunda en el sistema operativo Android para ofrecer una experiencia de manos libres y control total.

---

## 🚀 Características Principales

### 🎙️ Control de Voz Inteligente
- **Palabra de Activación**: Di "Hey JARVIS" para que el sistema empiece a escuchar, incluso en segundo plano.
- **ASR Avanzado**: Reconocimiento de voz optimizado para comandos naturales.
- **TTS Natural**: Respuestas fluidas con filtrado inteligente que omite la lectura de bloques de código tediosos.

### 📱 Integración con Ecosistema
- **WhatsApp**: Captura y lectura proactiva de mensajes entrantes.
- **Gmail**: Gestión de correos (leer, enviar y redactar borradores) mediante comandos de voz.
- **Control de Medios**: Control total de Spotify y YouTube (Reproducción forzada y búsqueda por voz).
- **Control de Sistema**: Ajuste de brillo, volumen, linterna y apertura de aplicaciones.

### 💻 Interfaz Futurista
- **Estética High-Tech**: Pantallas con efectos de partículas, gradientes cibernéticos y micro-animaciones HUD.
- **Visualizador de Código**: Renderizado de código Markdown con tipografía profesional y botón de copia al portapapeles.
- **Modo Diálogo**: Ventana de conversación continua de 5 segundos para comandos encadenados.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje**: Kotlin / Jetpack Compose
- **Arquitectura**: MVVM con Hilt (Inyección de dependencias)
- **IA**: OpenAI API (GPT-4o), Google Generative AI (Gemini)
- **Base de Datos**: Room (Persistencia de chat)
- **Seguridad**: DataStore (Preferences) y manejo de API Keys
- **Servicios**: Foreground Services para escucha continua y Notificación Listener.

## 📥 Instalación (Fase Beta)

Para probar la versión más reciente:
1. Ve a la sección de **[Releases](https://github.com/Instalaudi/jarvis-assistant/releases)**.
2. Descarga el archivo `app-release.apk`.
3. Instala en tu dispositivo Android (Requiere habilitar "Fuentes desconocidas").
4. **Permisos**: Asegúrate de otorgar permisos de Micrófono, Notificaciones y Contactos para el funcionamiento total.
